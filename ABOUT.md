# About Image-Hashing

Image-Hashing is a Python and HTML project for working with image hashes. It includes a web interface and supporting Python logic for image comparison workflows.

## Technology

- **Python** — core hashing and image-processing logic
- **HTML** — web interface and presentation
- **Batchfile** — small amount of Windows automation support
